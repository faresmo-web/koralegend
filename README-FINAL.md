# ⚽ KoraLegend - نظام المباريات المباشر

## 🎯 الميزات الرئيسية

### ⚡ تحديث مباشر كل ثانية
- تحديث حالة المباريات الجارية **كل ثانية**
- تحديث الدقائق والنتائج بدون إعادة تحميل
- تجربة مشاهدة حية وسلسة

### 🗑️ إخفاء تلقائي للمباريات القديمة
- المباريات التي انتهت منذ **أكثر من ساعتين** تُخفى تلقائياً
- الموقع يبقى نظيف ومرتب
- فقط المباريات الحديثة والجارية تظهر

### 🔄 تحديث البيانات كل دقيقة
- الصفحة تعيد تحميل نفسها كل **60 ثانية**
- يجلب أحدث البيانات من الـ Scraper
- يضمن أن المعلومات دائماً محدثة

### 💚 توفير الموارد
- التحديثات تتوقف عند إخفاء الصفحة
- تستأنف تلقائياً عند العودة
- استهلاك ذكي للموارد

## 🚀 التشغيل السريع

### الخطوة 1: شغّل الـ Scraper

**Windows (الأسهل):**
```bash
# اضغط دبل كليك على:
start-scraper.bat
```

**أو من Terminal:**
```bash
node scraper.js --daemon --interval=1
```

### الخطوة 2: افتح الموقع
افتح ملف `matches.html` في المتصفح

### ✅ تم! الآن:
- ⚡ التحديث المباشر يعمل كل ثانية
- 🗑️ المباريات القديمة تُخفى تلقائياً
- 🔄 البيانات تتحدث كل دقيقة
- 🔴 المباريات الجارية تظهر بشكل صحيح

## ⚙️ الإعدادات

### تغيير مدة التحديث المباشر

في `matches-data.js`، السطر ~6050:
```javascript
}, 1000); // 1000ms = 1 second
```

**خيارات:**
- `500` → نصف ثانية (أسرع)
- `1000` → ثانية واحدة (افتراضي)
- `2000` → ثانيتين (أبطأ)

### تغيير مدة إخفاء المباريات القديمة

في `matches-data.js`، السطر ~6220:
```javascript
if (hoursSinceMatch > 2) {
```

**خيارات:**
- `1` → ساعة واحدة
- `2` → ساعتين (افتراضي)
- `3` → 3 ساعات
- `24` → يوم كامل

### تغيير مدة تحديث البيانات

في `matches-data.js`، السطر ~6070:
```javascript
}, 60000); // 60000ms = 60 seconds
```

**خيارات:**
- `30000` → 30 ثانية
- `60000` → دقيقة واحدة (افتراضي)
- `120000` → دقيقتين

## 🐛 حل المشاكل

### المشكلة: البيانات لا تتحدث
**الحل:**
1. تأكد أن الـ Scraper يعمل في Terminal
2. تحقق من اتصال الإنترنت
3. شغّل `node scraper.js` مرة واحدة للتحديث الفوري

### المشكلة: المباريات الجارية تظهر كأنها انتهت
**الحل:**
- تم إصلاح هذه المشكلة
- تأكد أن ملف `matches-data.js` محدّث

### المشكلة: الصفحة تعيد التحميل بسرعة كبيرة
**الحل:**
- غيّر قيمة `60000` في `matches-data.js` إلى رقم أكبر

### المشكلة: المباريات القديمة لا تختفي
**الحل:**
- تأكد أن الـ Scraper يعمل ويحدث البيانات
- المباريات تُخفى فقط إذا مر عليها أكثر من ساعتين
